# Rutas del Equipo 2

Web estática con las 25 visitas. Para verla localmente, abre index.html en el navegador.

Para publicarla en Vercel, extrae el ZIP, sube estos archivos a la raíz de un repositorio e impórtalo en Vercel. Selecciona el preset Other, deja vacío el comando de compilación y utiliza la raíz del repositorio como directorio de salida.

La web incorpora datos de las fichas, incluidos nombres de los responsables. Si el acceso debe limitarse al equipo, configura la protección de acceso antes de compartir la URL.
